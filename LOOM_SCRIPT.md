## ♿ [1:00 - 1:30] Semantic HTML & Accessibility (a11y)

*"Accessibility was a core priority throughout development. We engineered strict semantic HTML5 markup—using native `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` tags.*

*If we inspect our contact form, every input is explicitly connected to its label via React’s `useId()` hook, featuring real-time validation, `aria-required`, `aria-invalid`, and accessible screen-reader error alerts. You can navigate the entire site using only the keyboard (`Tab`, `Shift+Tab`, `Escape`), highlighted by our high-contrast focus ring."*

## ⚡ [1:30 - 2:00] Performance Optimizations & Favorite Design Details

*"For performance, we preloaded Google Fonts (`Space Grotesk` and `Inter`) using Next.js font optimization, eliminating layout shifts completely. We also relied on pure CSS keyframe animations instead of heavy JavaScript loops, achieving a **95+ Performance** score and **100/100 Accessibility** score on Lighthouse.*

*My **top 3 favorite design details** are:*
1. *The **Growth pricing card**, featuring a subtle glowing gradient border that draws immediate user focus.*
2. *The **ambient background blobs** that float behind the hero section without consuming CPU animation cycles.*
3. *The **interactive metrics case-study showcase**, allowing users to cycle through real client revenue results with star ratings."*
